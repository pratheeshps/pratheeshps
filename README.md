## About me

I'm a Lead Software Engineer at [UST](https://www.ust.com) in India, modernizing the frontend of a banking product. Before that, I spent eight years on product frontend engineering at [AppViewX](https://www.appviewx.com).

My core stack is React and JavaScript, with Node.js and Java/Spring Boot on the backend. Lately, I've been applying that experience to AI tooling: agents that use tool calling, and servers built on the Model Context Protocol (MCP).

## Featured projects

### [Code Review Helper MCP](https://github.com/pratheeshps/code-review-helper-mcp)

An MCP server that gives AI assistants structured code reviews of JavaScript, including files fetched directly from GitHub repositories.

- Combines ESLint analysis, AST-aware TODO detection and naming checks into one report
- Includes recommendations for fixing what it finds, with tool behavior tested in Vitest

**Built with:** Node.js, MCP SDK, ESLint, Acorn, Octokit, Zod, Vitest

### [Wattwise Agent](https://github.com/pratheeshps/wattwise-agent)

A command-line AI agent that compares electricity bills and explains what changed in consumption and cost, currently using sample bill data.

- Runs a bounded tool-calling loop that stops with an error instead of running indefinitely
- Instructs the model to use retrieved data and a calculation tool, and never to invent missing data

**Built with:** Node.js, Claude API, tool calling
